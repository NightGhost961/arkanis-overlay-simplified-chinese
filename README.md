# Arkanis Overlay 简体中文补丁

这是基于 ArkanisOverlay 源码制作的本地构建补丁，不是官方发布版。

- 应用界面通过 `wwwroot/js/zh-CN.js` 翻译常用导航、搜索、贸易、库存、机库和设置控件。
- 游戏条目使用根目录 `localization/社区翻译对照.ini` 中的《星际公民》社区术语；显示为“中文（英文）”，保留 UEX 英文名称以免影响识别与搜索。
- 直接输入中文术语搜索时，补丁会把已索引的术语扩展为对应英文名称，再交给原有 UEX 搜索逻辑。

限制：该社区术语文件没有 Overlay 自己的英文界面对照，因此这不是官方意义上的完整 i18n。动态提示、较少使用的对话框和未能从术语库精确提取的游戏条目仍可能显示英文。不要将本地构建产物覆盖到官方安装目录；官方自动更新也会替换自定义版本。
